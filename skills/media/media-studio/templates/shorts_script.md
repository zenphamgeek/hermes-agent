# YouTube Shorts Script Template — ZENPHAM

## Cấu trúc (Tổng thời lượng: 50-60 giây)

### 🎯 HOOK (0-3 giây)
Mở đầu bằng 1 trong 3 kiểu:
- **Câu hỏi gây tò mò**: "Bạn có biết [fact bất ngờ]?"
- **Thách thức**: "[X] mà 90% developer chưa biết"
- **Tuyên bố mạnh**: "[Công nghệ Y] vừa thay đổi hoàn toàn cách chúng ta [Z]"

Không chào hỏi. Không giới thiệu bản thân. Đi thẳng vào hook.

### 📝 NỘI DUNG (3-50 giây)
- Giải thích ngắn gọn, dùng ngôn ngữ đời thường
- Tối đa 3 ý chính (mỗi ý ~15 giây)
- Dùng ví dụ cụ thể, so sánh dễ hiểu
- Mỗi câu ngắn, dứt khoát, không lan man
- Dùng con số cụ thể khi có thể

### 📢 CTA (50-60 giây)
- "Follow để không bỏ lỡ tips AI mỗi ngày"
- "Comment bên dưới: bạn nghĩ gì về [topic]?"
- "Like + Share nếu bạn thấy hữu ích"

## Quy tắc viết
- **Giọng văn**: Năng lượng, tự tin, như đang nói chuyện 1-1 với bạn
- **Độ dài**: Khi đọc tự nhiên = 50-55 giây (khoảng 150-180 từ tiếng Việt)
- **Không dùng**: thuật ngữ khó mà không giải thích, câu dài quá 2 dòng
- **Subtitle-friendly**: Mỗi câu nên kết thúc tự nhiên để subtitle hiển thị đẹp

## Ví dụ

```
[HOOK]
Vibe Coding sẽ thay đổi cách bạn lập trình — trong 60 giây tôi giải thích tại sao.

[NỘI DUNG]
Vibe Coding không phải copy-paste code từ ChatGPT.
Nó là nghệ thuật mô tả ý tưởng bằng ngôn ngữ tự nhiên, rồi để AI sinh code cho bạn.

Bước 1: Bạn nói cho AI biết bạn muốn gì — bằng tiếng Việt luôn.
Bước 2: AI sinh code, bạn review và tinh chỉnh.
Bước 3: Lặp lại cho đến khi sản phẩm hoạt động.

Tại sao nó hiệu quả? Vì bạn tập trung vào giải quyết vấn đề, không phải cú pháp.
Một developer dùng Vibe Coding có thể ship sản phẩm nhanh gấp 3 lần bình thường.

[CTA]
Follow ZENPHAM để cập nhật tips AI và Vibe Coding mỗi ngày. Comment: bạn đã thử Vibe Coding chưa?
```
