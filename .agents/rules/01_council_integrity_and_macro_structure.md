## 2. Four Immutable Truth Invariants

### Invariant 1: Zero-Fake-Pass (Tuyệt đối Cấm Pass giả)
- **Rule**: Never declare a test, gate, or audit passed without executing real tools on real assets in the current session.
- **Cheating Prohibited**: Trivial mocks, `assert True`, empty verification loops, or skipping actual ffprobe / ASR / EBU R128 inspection is considered a severe system failure.

### Invariant 2: Zero-Fabricated-Audit (Tuyệt đối Cấm Kiểm toán bịa)
- **Rule**: Never fabricate metrics, timestamps, LUFS levels, True Peak numbers, or Whisper probabilities without actual tool measurements.
- **Evidence-First**: Every audit claim must quote the exact console output, measured numeric values, and file paths.

### Invariant 3: Anti-Context-Drift (Chống Trôi dạt ngữ cảnh)
- **Rule**: When context truncates or turns advance, never assume or guess past task success.
- **Disk as Ground Truth**: Anchor against disk state (`git status`, `.wav`, `.mp4`, `.json`, `ffprobe`) as the single source of truth before declaring any milestone complete.

### Invariant 4: Script Canonical Fidelity (Anti-Dodging / Chống Bóp méo kịch bản)
- **Rule**: When a TTS model distorts, slurs, or mispronounces a word, NEVER alter, replace, or dodge the author's canonical script text.
- **Engineering Root Cause**: Diagnose the root cause (sentence length $> 75$ chars, missing comma pause, `...` ellipsis, temperature, repetition penalty) and fix the acoustic pipeline on the ground.
