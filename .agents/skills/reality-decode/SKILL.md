## 4. Lệnh Vận Hành Nhanh (CLI Commands)

### 4.1. Kiểm tra kết nối kênh
```bash
.venv/bin/python skills/media/youtube-publisher/scripts/yt_publish.py --check --channel REALITY_DECODE
```

### 4.2. Xuất bản Video tự động qua Kịch bản Markdown
```bash
# Xem trước siêu dữ liệu SEO (Dry-run)
.venv/bin/python skills/media/youtube-publisher/scripts/yt_publish.py upload \
  --video output/ep01_reality_decode_master.mp4 \
  --md scripts/ep01_why_ai_agents_fail.md \
  --channel REALITY_DECODE \
  --dry-run

# Xuất bản chính thức (Private duyệt trước hoặc Public)
.venv/bin/python skills/media/youtube-publisher/scripts/yt_publish.py upload \
  --video output/ep01_reality_decode_master.mp4 \
  --md scripts/ep01_why_ai_agents_fail.md \
  --channel REALITY_DECODE \
  --privacy private
```

### 4.3. Quản lý Danh sách phát (Playlists)
```bash
# Tạo playlist mới
.venv/bin/python skills/media/youtube-publisher/scripts/yt_publish.py playlist-create \
  --title "AI Systems Decoded" \
  --description "Giải mã bản chất kiến trúc và giới hạn của các hệ thống AI hiện đại." \
  --channel REALITY_DECODE

# Thêm video vào playlist
.venv/bin/python skills/media/youtube-publisher/scripts/yt_publish.py playlist-add \
  --playlist-id PL_XXXXXX \
  --video-id VIDEO_ID \
  --channel REALITY_DECODE
```
